# Patricia Pricken — Artist Website

A free, minimalist artist portfolio built with plain HTML, CSS and JavaScript.

## Publish with GitHub Pages

1. Create a GitHub account if needed.
2. Create a new repository named `YOUR-USERNAME.github.io`.
3. Upload everything in this folder, including the `images` folder.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. Your site will appear at `https://YOUR-USERNAME.github.io/`.

## Editing

- Change the artist statement and captions in `index.html`.
- Replace images in `images/` and update the corresponding filenames in `index.html`.
- Styling is in `style.css`.
- The image lightbox is in `script.js`.

No paid hosting, framework or build process is required.
